# 🎁 The Elusive Button (Harmless Prank App)

An impossible-to-click, evasive button web app designed to playfully troll your friends, coworkers, or classmates.

## ✨ Features
- **Proximity Radar**: Detects cursor distance and flees *before* the user even hovers over it.
- **Smart Evasion Physics**: Always darts to the furthest spot on the screen relative to mouse/touch.
- **Escalating Taunts**: Dynamic dialogue bubbles with progressively cheeky comments.
- **Web Audio Sound Effects**: Integrated dynamic whooshes and win chimes.
- **Mobile Touch Ready**: Instantly teleports away on mobile touch screens.
- **Cheater / Win Easter Egg**: Confetti celebration if clicked via tab+enter or superhuman reflexes.
