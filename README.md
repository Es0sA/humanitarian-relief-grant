# 🛡️ Humanitarian Relief Grant — The Elusive Button Portal

A deceptively realistic, impossible-to-click confirmation portal disguised as an official relief grant disbursement page. Designed as a harmless prank with dynamic evasive physics and genuine-looking urgency mechanics.

---

## ✨ Features

- **🏛️ Hyper-Realistic Design**: Styled after official government / NGO portals with reference numbers, SSL badges, and pending direct deposit statuses.
- **⏱️ 90-Second Urgent Countdown**: Realistic countdown timer that turns urgent in the final 20 seconds.
- **🔄 Session Expiration & Retry**: Automatically locks down with an official expiration overlay when time runs out, with a one-click **Retry Claim** button that resets the session and repositioning.
- **⚡ Proximity & Touch Radar**: Detects cursor proximity and mobile finger touches, dodging smoothly across the viewport.
- **📐 Dynamic Glitch Mechanics**: Subtle scale, rotation, and evasive angle variations that make it appear as though the user's touchscreen or sensor is glitching.
- **📱 Fully Responsive**: Optimized for iOS Safari, Android Chrome, and desktop web browsers.
